HemoSphere Alta · Minimally-Invasive (IQ Sensor) Mô phỏng đào tạo
Các thao tác chạm trên màn hình
  • Ô thông số (bên phải biểu đồ): mở Parameter Configuration với các tab Select Parameter, Set Targets, Y Scale. Chạm tên thông số ở góc dưới ô để đổi sang thông số khác.
  • Trục thời gian dưới biểu đồ: đổi Time Range; công tắc ở góc phải chuyển Graphical/Tabular trend.
  • Screen: chọn Trend, Cockpit hoặc Split (Physiology, Goal Positioning, thêm biểu đồ).
  • Clinical Tools: Hypotension Prediction Index, Goal Directed Therapy, Fluid Responsiveness Test, Derived Value Calculator, Events & Intervention.
  • Alarm: chạm để tạm dừng âm 2 phút; chạm giữ để mở Pause, Reset, Silence 1–5 phút.
  • Thanh trạng thái: chạm dòng báo động để xem danh sách; chạm góc phải để chỉnh độ sáng, âm lượng, khóa màn hình; chạm HPI để mở màn hình phụ HPI.
  • Patient, Zero, Settings, Help trên thanh dưới.
